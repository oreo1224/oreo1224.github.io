# 掲示物ジェネレーター

写真を参考にした掲示物を、A4横（297 × 210 mm）で作成する静的Webサイトです。

## 使い方

1. 右上に入れるロゴ画像を選択するか、画像のアップロード欄にドロップします。未選択の場合、ロゴ部分は空白です。
2. 虹色部分の文面（改行で最大6行）と、下部の4行を編集します。虹文字の「太字（Bold）」「斜体（Italic）」スイッチで、それぞれ独立してオン／オフを切り替えられます。「字間の調整」は元の字間から−2〜＋5mm、0.1mm刻みで全行に反映します。スライダーと数値入力が連動します。調整量0では従来の字間を維持し、英数字のみの先頭行には元々の字間12 SVG単位も加算されます。プレビューは即時に更新され、長い行は幅に合わせて自動調整されます。
3. 「位置・大きさ」で対象を選び、X（左右）・Y（上下）のスライダーを動かします。元の位置から±100mm、0.5mm刻みで調整でき、数値も直接入力できます。虹文字全体・虹文字の各行・ロゴ・「（本物）」・赤い矢印・下部4行を個別に動かせます。虹文字全体と各行の移動量は加算されます。「この対象を元の位置へ」と「全位置を戻す」は文面・ロゴ・文字スタイル・大きさを維持して位置だけ戻します。
4. 同じ対象を選んだまま「大きさ」のスライダーで、25〜200%、1%刻みに拡大縮小できます。数値入力にも対応し、100%が元の大きさです。虹文字全体と各行の倍率は掛け合わせます（全体80%、行150%なら、その行は元の120%）。「大きさを100%に戻す」は選択中の対象だけ、「全サイズを戻す」は全対象の大きさを戻し、位置や文面は維持します。「（本物）」は赤い背景も一緒に拡大縮小します。
5. 「印刷 / PDF保存」を押し、A4・横向き・倍率100%・余白なしで印刷します。PDFは印刷画面の保存先から選択します。ブラウザ側のヘッダーとフッターはオフにしてください。

「（本物）」の文言と赤い矢印の形は固定です。矢印の位置と大きさ、「（本物）」の赤い背景を含めた位置と大きさを調整できます。画像はPNG・JPEG・WebP・GIF・SVGに対応し、最大12MBです。GIFは読み込み時点のフレームを使用します。ロゴの縦横比と透明部分を維持します。紙の外にはみ出した部分はプレビュー・印刷ともに表示されません。画面上部の「リセット」は文面・ロゴ・文字スタイル・すべての位置と大きさを初期状態に戻します。斜体の初期状態はオン、字間の調整量は0mm、大きさはすべて100%です。

## ローカル起動

このディレクトリで実行します。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで <http://127.0.0.1:4173/> を開きます。ビルドやパッケージのインストールは不要です。GitHub Pagesでは、このディレクトリをそのまま配信できます。

## 印刷・データについて

- 印刷時は編集画面を隠し、掲示物のみをA4横1ページで出力します。
- 文字、矢印、色付きラベルはSVGで描画し、拡大・印刷しても鮮明です。
- 虹色部分は、文面全体で共有する連続グラデーションを文字の形でクリッピングしています。1文字の内部も滑らかに色が変わります。
- 虹色の文字は斜体オンで12度傾き、オフで直立します。薄い右下の影は文字の複製で描画し、字間・斜体の変更を反映します。印刷でも輪郭を保ちます。
- 「34,000名…」の行は黒い文字に白と黒の二重縁取りを付けています。「全国の市町村業務…」の行は、下に映る反射が徐々に薄くなる効果を付けています。文面の編集と位置変更は各効果にも反映されます。虹文字のクリッピングと影も同じ位置で描画します。
- 拡大縮小は文字の幅を整えた後に適用し、選んだ倍率で描画します。下部4行は左端のベースライン、虹文字の各行は中央のベースライン、虹文字全体・ロゴ・ラベル・矢印は配置の中心を基準にします。X/Yの移動量は拡大縮小で変わりません。影・縁取り・反射のマスクも文字と一緒に拡大縮小します。虹文字の各行の影は、影の移動量も倍率に合わせます。
- 虹文字は同梱のHGP創英角ポップ体と角ゴシックを選択できます。端末へのフォントインストールは不要です。フォント読込失敗時は案内を表示し、角ゴシックに切り替えます。元写真とブランドロゴの正確な使用書体は未特定です。
- HGP創英角ポップ体は単一ウェイトのため、Boldオンはブラウザの合成太字です。
- BIZ UDPゴシックはRegular・Boldを同梱し、通常／太字を実際の別ウェイトで切り替えます。「絶対に 光ファイバ芯線 抜くな！ 曲げるな！！」の行は、字形自体が太いHGP創英角ゴシックUBを使用します。CSSでは900のウェイトとして登録し、合成太字を使わず描画します。他の下部3行はBIZ UDPゴシックBoldを使用します。
- 背景グラフィックをオフにしても、SVG内の色は印刷されます。
- プリンターが余白なし印刷に対応していない場合は、印刷設定の「印刷可能領域に合わせる」を使用してください。
- ロゴはブラウザ内でPNGに変換し、外部サーバーには送信しません。入力内容や画像は保存しないため、再読み込みや画面を閉じると初期状態に戻ります。

## 確認済みの動作

- Chromeで虹色部分・下部4行の編集、ロゴの追加・削除・読込エラー、リセット、印刷ボタンを確認。
- 320・390・768・1280px幅で横方向のはみ出しがないことを確認。
- Chromeから生成したPDFがA4横1ページになり、ロゴ・虹色・固定ラベル・矢印・各文面が表示されることをPDFの画像化でも確認。
- 連続グラデーション・影・斜体を変更後、ブラウザの表示とA4横1ページのPDFを確認。PDF内にBIZUDPGothic-Boldが埋め込まれていることを確認。
- 虹色の文面を長文・6行に変更しても、文字とクリッピングの形状が同期することを確認。
- Boldのクリック／キーボード切り替え、RegularとBoldの読み込み、文面の編集内容が縁取り・反射にも反映されることを確認。
- Boldオン／オフの両方でA4横1ページのPDFを生成し、オフのPDFにはRegularと下部用のBoldが埋め込まれることを確認。PDFの画像化で二重縁取りと反射のフェードも確認。
- 追加されたHGP創英角ポップ体の読込・実際の字形・Bold切り替えをChromeで確認。位置変更後のBoldオン／オフPDFがA4横1ページで出力され、通常ウェイトのPDFにHGPSoeiKakupoptaiが埋め込まれることを確認。BoldオンのPDFを画像化し、文字・ロゴ・縁取り・反射・影の位置を確認。
- 虹文字全体・虹文字の各行・ロゴ・「（本物）」・下部4行のXY移動、スライダーのキーボード操作と数値入力の同期を確認。6行目の移動と、行を減らしたときの選択対象の切り替えを確認。
- 字間の正負の調整、スライダーと数値入力の同期、斜体スイッチのクリック／キーボード切り替えを確認。字間・斜体の変更後もクリッピングと影の字形が同期することを確認。
- 赤い矢印のXY移動と、太いHGP創英角ゴシックUBの表示を確認。字間を広げて斜体オフ／字間を詰めて斜体オンのPDFを生成し、A4横1ページとHGPSoeiKakugothicUBの埋め込みを確認。PDFの画像化で字間・直立した文字・影・矢印の移動・太いゴシック体を確認。
- 虹文字全体・各行・下部4行・「（本物）」・矢印の個別拡大縮小、スライダーのキーボード操作と数値入力の同期を確認。位置だけのリセットが大きさを維持し、大きさだけのリセットが位置を維持することを確認。6行目の拡大と文字・クリッピング・影の同期も確認。
- 各対象の倍率を変えたPDFがA4横1ページになり、PDFの画像化でも虹文字の影・二重縁取り・反射・ラベルの大きさが反映されることを確認。
- JavaScriptの構文確認済み。実機プリンター、Safari・Firefoxの印刷は未検証。
